# Henry Mosiali — Portfolio

A modern portfolio website showcasing my work as a Full-Stack Web Developer.

## Live Website

[Visit the portfolio](https://henry-proj.vercel.app)

## About

I've been exploring and building for the web since 2020, with 4+ years of hands-on development experience across frontend and backend technologies. This portfolio brings together selected projects, technical skills, and key learning milestones.

## Features

- Responsive portfolio experience
- Animated neural-network hero
- Featured project showcase
- Development journey and certification milestones
- Technology-focused skills section
- Contact form and professional contact details
- SEO and social sharing metadata

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Testing

The project includes tooling for unit and end-to-end testing. Run the available test scripts defined in `package.json` for the current test suite.

## Deployment

The application is a Vite React project and can be deployed to a static hosting platform such as Vercel.

## Repository

This repository contains the source code for the portfolio website, including its UI components, animations, project content, and configuration.
