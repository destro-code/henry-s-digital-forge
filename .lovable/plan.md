# Henry Mosiali — Web Developer Portfolio

## Concept: "The Architect's Network"

A dark, immersive portfolio where the visual metaphor is a living neural network mesh — representing your deep expertise in backend architecture and interconnected systems. The user scrolls through what feels like navigating inside a sophisticated system you've built.

## Design System

- **Theme**: Deep charcoal black (`#0a0f0a`) with emerald green (`#00ff88`) glowing accents and subtle gray tones
- **Typography**: `Inter` or `Space Grotesk` for headings (modern, techy), `JetBrains Mono` for code/accent text
- **UI Principles**: Generous whitespace, smooth scroll-triggered animations, glassmorphism cards with green glow borders
